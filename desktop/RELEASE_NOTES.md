Portal Desktop 0.1.5

- Windows 改用 NSIS 一键安装：使用默认目录，显示安装进度，按当前用户安装，完成后自动打开客户端。
- 客户端内升级与手动覆盖安装使用同一套安装流程。替换文件前停止客户端管理的 Portal，升级后保留配置、凭据、工作目录和 Kits，并恢复原来的运行设置。
- 修复 Windows 留有 Portal 配置但计划任务已丢失时的启动失败。客户端正常打开并保留配置；明确启动客户端管理的 Portal 时可恢复计划任务。系统权限错误使用可读文字显示。
- 修复 Windows 安装助手随旧客户端退出而提前结束，以及安装后无法通过快捷方式自动启动的问题。
- 集成 Seed Garden，完善 Town 阅读、回复和引用草稿交互；SBS 开关在刷新后与服务端状态同步。
- 修复 Windows CI 管理员会话下的安装测试隔离：使用普通用户权限运行完整安装升级流程，等待真实窗口与配置目录就绪，并保留失败诊断。
- 更新 Town SDK 测试，验证篝火、私信和围炉回复的目标与请求内容；增加 Windows 原生安装、客户端内升级、运行中覆盖安装和计划任务恢复验证。

客户端统一携带和管理 Heart Portal 0.8.3，源码锁定至 ca92277f31734406ea097559c5ab707582bc9a6f。升级后使用新客户端配套的 Portal，不单独更新引擎；升级期间本机任务会中断且不会重放，请先完成任务并保存草稿。

macOS ARM64 提供 Developer ID 签名的 DMG 和升级 ZIP，公证按 Portal 源仓策略暂缓。Windows x64 提供 NSIS Setup 和 ZIP，目前尚未配置 Authenticode 签名，Windows 仍可能显示发布者或 SmartScreen 提示。请从本仓库下载，使用 SHA256SUMS.txt 核对完整性。
